## Free, open source, on Hex

Refrakt is a Gleam package published on [Hex](https://hex.pm/packages/refrakt) under the MIT license. It targets the BEAM only: one compilation target, one server model, Mist as the HTTP server.

The repository has two complete example apps generated with the CLI: a [blog](https://github.com/raskell-io/refrakt/tree/main/examples/blog) on PostgreSQL with auth and an island, and a [task list](https://github.com/raskell-io/refrakt/tree/main/examples/tasks_app) on SQLite. API docs are on [HexDocs](https://hexdocs.pm/refrakt), and the [guides](https://github.com/raskell-io/refrakt/tree/main/docs) cover routing, handlers, views, forms, databases, auth, testing and deployment.
