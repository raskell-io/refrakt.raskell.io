One command, full CRUD

refrakt gen resource writes a handler with seven actions, Lustre views, a typed form with validation, a domain type, a repo with raw SQL, a migration and tests. Then it adds the routes to your router and runs gleam format on everything it wrote.

Add --api for a JSON handler under /api/ instead of HTML views, or --belongs-to posts to add a post_id foreign key.

Principles

Before anything is added to Refrakt, it has to make a new Gleam developer more productive in their first hour.

  1. Conventions over assembly. One project layout, one routing shape, one way to structure handlers, views, forms and repos. Spend your time on features, not on file organisation.
  2. Generated code is your code. Every file the CLI writes is plain Gleam you can read, change and keep. There is no hidden framework layer behind it.
  3. No magic, no macros. Gleam has no metaprogramming and Refrakt doesn't fake it. Routing is pattern matching, views are functions, validation is functions.
  4. Built on the ecosystem. Wisp handles HTTP, Lustre renders HTML, Mist serves it, Pog or Sqlight talk to the database. Refrakt adds conventions and generators on top.
  5. Boring where boring is good. CRUD, forms, validation, sessions and layouts come first, and they should just work.

Three layers, one direction

Every Refrakt app has the same shape. The web layer handles HTTP and HTML, the domain holds your types and logic, the data layer talks to the database.

  • ✓ web/ → domain/, data/
  • ✓ data/ → domain/
  • ✗ domain/ → web/, data/

Domain modules have no Wisp, Lustre, Pog or Sqlight imports: just your types and functions.

web/handlers, views, forms, layouts, components, middleware
domain/pure Gleam types and functions
data/repos with raw SQL, migrations

The commands

The CLI is a code generator and a few dev helpers. Your app never calls it at runtime.

new <name>Create a project, optionally with --db postgres or --db sqlite
gen resource <name> <fields…>Full CRUD: handler, views, form, domain type, repo, migration, tests
gen page <name>A handler and a GET route
gen authRegister, login, logout, sessions and a require_auth middleware
gen island <name>A Lustre client-side island and its embed helper
gen live <name>A Lustre server component over WebSocket
gen migration <name>An empty, numbered SQL migration
migrate · seedRun pending migrations · run seeds
routesPrint the route table from router.gleam
dev · buildDev server with rebuild on change · compile islands to JavaScript
